# 🔍 Google Search

A lightweight, browser-based custom search engine powered by the **Google Custom Search JSON API**

---
👉 [View Live on GitHub Pages](https://suneerkhan.github.io/search-engine-/)

## 🚀 Features

- Clean and minimal search interface
- Real-time search results powered by Google Custom Search API
- Fast, client-side rendering with no backend required
- Fully responsive design for desktop and mobile
- Deployed and accessible via GitHub Pages

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure and layout |
| CSS3 | Styling and responsiveness |
| JavaScript (Vanilla) | Logic and API integration |
| Google Custom Search JSON API | Search results |
